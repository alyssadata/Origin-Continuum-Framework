## 4. Inference Levels

Study 1 must keep the following levels separate:

1. **Trial** — one execution of a frozen prompt sequence under a specified condition.
2. **Condition** — a defined combination of model, context, history, memory, retrieval, support, and prompt factors.
3. **Comparison** — a prospectively defined contrast between matched or explicitly partially matched conditions.
4. **Trajectory** — an ordered linked sequence used only where continuity, divergence, drift, or return is evaluated.
5. **Program-Level Origin Gate** — the conclusion produced by the frozen aggregation rule across registered comparisons.

A condition-level qualifying expression does not by itself clear the program-level gate.
